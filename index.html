Action Recorder PDF
网页操作自动截图与步骤记录工具

自动记录网页点击、输入等关键动作，生成带标注截图的操作步骤，并支持步骤编辑、演示回放、PDF / Word / JSON 导出，用于产品操作手册、培训材料与项目交付文档制作。

查看 GitHub 源码打开测试页面

自动记录操作

录制开始即保存基线画面，并根据点击、输入等关键动作自动生成步骤。

截图 + 标注

点击位置自动绘制醒目标记；输入类操作保留结构化说明，并对敏感字段自动脱敏。

文档导出

操作记录可整理为 PDF、可编辑 Word 兼容文档或 JSON 备份，方便交付与二次编辑。

项目价值

将传统“人工操作 → 截图 → 标注 → 排版”的重复流程，改造成“操作即记录 → 自动生成步骤 → 编辑与导出”的轻量自动化工作流。

核心能力

点击 / 输入捕获敏感信息脱敏步骤编辑与排序当前屏幕重截演示回放本地会话恢复PDF / Word / JSON
